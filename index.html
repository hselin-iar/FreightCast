Quality gates (§6.1)

  • schema — malformed rows rejected, not passed through
  • freshness — daily feeds >2 days old raise an alert
  • gaps — weekend/holiday forward-filled
  • plausibility — draft cannot be negative or absurd
  • manual — port constraints queued for sign-off

Model gate (§6.2)

Walk-forward only. A pair may populate forecast_object iff it beats naive random-walk on MAE. n<500 skips XGBoost. Ablation runs every retrain so a dead feature is visible here, not hidden in a black box.
